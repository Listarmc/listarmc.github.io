Description

Call of the Night GUI-Only Resource Pack

This is a GUI-only resource pack, so you can freely use it with other resource packs — just place it on top of the resource pack you already use. This pack is themed after "Call of the Night" and features a dark purple, pink, and light blue color palette. Customized hot bar and unique images for each container better match the series' aesthetic. Like some of my newer packs, this one includes scaled containers, which required significant re-adjustments after resizing. This makes the pack visually distinct from my older releases.

If you'd like to see alternative color schemes in the future — such as white & red or any other combinations — feel free to suggest them, and I'll consider it. If you find any bugs, please report them so I can fix them as soon as possible.
