Listar MC Admin

Edits the site straight on GitHub. Every publish is one commit to your repo, and GitHub Pages deploys it.

Which token do I need?
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → your site repo.
  3. Permissions → Contents: Read and write (required).
  4. Optional: Actions: Read and write to see deploy status and use “Redeploy”.

The token is only sent to api.github.com. It is kept in this browser tab (or on this device if you tick “Remember”), never in the repo.
